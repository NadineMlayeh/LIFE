Totally fair — that's a completely legitimate reason, not laziness. Composing multiple external assets into something that reads as cohesive (matching perspective, lighting direction, color harmony) is a real design skill, and getting it visibly wrong is worse than a simpler but consistent code-only version. Committing to code-only removes that whole risk category. Here are both, fully detailed, ready to hand to an agent.

============================================================
PROMPT 1 — Layered CSS/SVG + Framer Motion ("soft-UI" room)
============================================================

Build the LIFE main room as a single React component, using ONLY hand-coded SVG shapes and CSS — no imported images, icon libraries, or external assets of any kind. Everything must be drawn with SVG primitives (paths, rects, circles, ellipses, polygons) and styled with CSS gradients, shadows, and blur.

Overall aesthetic: warm, cozy, elegant, tactile, calm, slightly magical. Explicitly avoid: flat corporate dashboard look, sharp cold edges, cartoonish/childish shapes, videogame asset style.

Color palette (use consistently across every object):
- Wall background: warm cream #F3E4D0
- Floor: warm honey wood #C9A77C, with a slightly darker rug tone #B98A5E
- Wood/frame elements (mirror frame, bookshelf frame, clock frame): #7A5233 to #6E4A2E
- Accent 1 (coral, used sparingly — mailbox, one book, one highlight): #D85A30
- Accent 2 (muted teal, used sparingly — map pins, one book, mirror glass tint): #1D8A6B
- Accent 3 (warm amber, used sparingly — key, one book): #C98A2E
- Text/labels: warm dark brown #5C4630, small (12–14px), soft rounded sans-serif font

Depth technique — this is the most important instruction: every object must look "raised" off the wall using a soft-UI / claymorphic technique: a soft light-colored highlight shadow on the upper-left edge and a soft darker shadow on the lower-right edge of each shape (dual-direction box-shadow or SVG filter), generous corner rounding on every rectangular shape, subtle linear gradients (not flat fills) on any surface meant to feel three-dimensional (wood panels, book covers, the mirror glass), and a soft blur (2–6px) on background/decorative layers to separate them visually from foreground interactive objects. Layer the scene in this depth order, back to front: wall → window → map → clock → bookshelf → mirror → floor/rug → key → mailbox, with each layer getting very slightly larger drop shadows as it comes forward.

Room layout and objects:

1. Mirror (upper-left area): oval wooden frame, soft gradient glass in pale teal-blue, one soft diagonal highlight streak across the glass. On hover: gently scale up (1.03x) and the glass tint brightens. On click: mirror scales up further, room around it blurs and fades, transitioning to a personal space view.

2. Bookshelf (right side): wooden frame with 2–3 visible shelves (horizontal dividers), 10–15 books as vertical rounded rectangles in varied heights and the palette's accent colors, each book slightly offset/tilted a few degrees for a natural non-uniform look (never perfectly aligned — this fakes hand-placement without needing real assets). On hover over a single book: that book lifts and tilts slightly forward with a small shadow increase. On click: the whole shelf scales forward and opens into the library view.

3. Clock (top center): circular wooden-framed clock face in soft cream, simple minute/hour hands, small tick marks (no numbers needed, keep it minimal). On hover: subtle pulse/glow. On click: transitions into the vertical timeline view.

4. Window (top right or opposite the mirror): rounded rectangular wooden frame, warm gradient "sky" fill transitioning between two warm gradient stops that shift automatically based on the visitor's local device time (morning = pale gold, midday = bright warm yellow, evening = deep orange/pink, night = deep muted blue with a soft "moon" circle). Purely atmospheric, not clickable.

5. Map (small, wall-mounted, near the mirror): a simple rounded rectangle "framed" shape with a handful of small circular dot markers scattered inside in teal (visited) and neutral grey (not visited) — do not attempt an actual world map illustration, keep it abstract/symbolic. Clickable, opens visited-places view.

6. Privacy key: small key silhouette (circle + rectangle "teeth", built from basic shapes) in amber, hanging from a small peg/hook shape. On hover: gentle swing rotation. Click opens privacy settings.

7. Mailbox: small rounded box on a thin post near the floor, in coral, with a small triangular "flag." On hover: gentle bounce. Click opens sharing.

Animation rules (Framer Motion): all hover transitions under 200ms, all click/room transitions 300–500ms with an ease-out curve. Never animate more than the object being interacted with plus a subtle blur/dim on the rest of the room — keep transitions calming, not busy.

Responsiveness: on narrow/mobile viewports, stack the objects into a simple vertical scrollable list of "rooms" rather than shrinking the whole scene — preserve full interactivity, simplify the spatial layout only.

Build the mirror, bookshelf, and clock first as the three fully working "hero" objects with real hover/click behavior before adding the remaining four.

============================================================
PROMPT 2 — React Three Fiber (Three.js) primitives-only room
============================================================

Build the LIFE main room as a 3D scene using React Three Fiber (@react-three/fiber) and @react-three/drei, constructed ONLY from primitive geometries (boxGeometry, cylinderGeometry, sphereGeometry, planeGeometry, torusGeometry) and MeshStandardMaterial — no imported .glb/.gltf model files, no image textures loaded from disk or URL. The only external dependency allowed is a drei <Environment preset="apartment"> (or "sunset") for realistic ambient lighting/reflections, since this ships inside the npm package rather than being something you source yourself.

Overall aesthetic: same warm, cozy, tactile, slightly-magical direction as a real furnished room at golden hour — not a stark tech demo, not a sci-fi environment, no harsh cold lighting.

Material palette (approximate hex + roughness/metalness):
- Walls/floor: warm cream #F3E4D0 / honey wood #C9A77C, roughness 0.9, metalness 0 (fully matte)
- Wood frames (mirror, bookshelf, clock): brown #7A5233, roughness 0.6, metalness 0
- Mirror glass: pale teal #BFD9DE, roughness 0.05, metalness 0.6 (so it actually catches reflections from the Environment preset)
- Books: vary between coral #D85A30, teal #1D8A6B, amber #C98A2E, cream #EADFC8, roughness 0.8, metalness 0
- Key/mailbox accents: amber/coral as above, roughness 0.4, slight metalness 0.2 for a soft polished look

Lighting: one warm directionalLight positioned like late-afternoon sun coming through the window (soft orange tint, moderate intensity), the drei Environment preset for ambient fill/reflections, and soft shadows enabled everywhere (<Canvas shadows>, shadow-mapSize at least 1024, PCFSoftShadowMap) — avoid hard-edged game-style shadows.

Objects and camera: a fixed, slightly elevated camera angle looking into the room (not a free-roam first-person camera — this should feel like looking into a diorama, not walking through a level).

1. Mirror: a flattened cylinder (or torus + disc) as an oval frame with the mirror material disc inset. Hover: slight scale-up + gentle Y-axis rotation. Click: camera dollies/zooms toward it before transitioning.

2. Bookshelf: an open box frame (three box "shelves" stacked) with 10–15 thin box "books" of varied height/color standing on the shelves, each rotated a few degrees differently so they don't look perfectly uniform. Hover over one book: it tilts/slides forward slightly.

3. Clock: a flattened cylinder face with two thin box "hands" and small box tick marks around the rim.

4. Window: a large plane with a gradient-colored MeshBasicMaterial (not affected by lighting) that shifts between warm gradient stops based on the visitor's local device time — same morning/midday/evening/night logic as the CSS version.

5. Map: a flat plane with small raised cylinder "pins" in teal (visited) and grey (not visited) — keep it abstract/symbolic, not a literal world map.

6. Privacy key: a small torus + thin box combo hanging from a small hook (short cylinder), with a gentle idle swing rotation via useFrame.

7. Mailbox: a small box on a thin cylinder post with a tilted box "flag."

Interaction: use drei's <Html> or simple raycasting via onPointerOver/onClick for hover/click states — hover triggers a subtle scale + emissive glow increase on that object only; click triggers a camera transition (using drei's CameraControls or a manual lerp) zooming toward the object before the scene fades to the relevant feature view.

Build the mirror, bookshelf, and clock first as fully working hero objects with real hover/click/camera-zoom behavior before adding the remaining four.
